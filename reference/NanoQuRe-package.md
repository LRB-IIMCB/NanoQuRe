# NanoQuRe: Quality Control for Oxford Nanopore Sequencing

Provides quality control tools for Oxford Nanopore Technologies (ONT)
sequencing data. Reads sequencing summary files produced by Guppy or
Dorado and generates interactive plots and summary tables covering
read-length distributions, base quality scores, cumulative yield,
sequencing throughput, translocation speed, and pore channel activity. A
single call to generate_report() renders a self-contained HTML report
from one or more summary files, with automatic single-sample or
multi-sample layout selection.
