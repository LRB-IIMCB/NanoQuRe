# Test if x is a single non-empty character string

Test if x is a single non-empty character string

## Usage

``` r
is_string(x, min.chars = 1, null.ok = FALSE)
```

## Arguments

- x:

  Object to test

- min.chars:

  Minimum number of characters \[1\]

- null.ok:

  Allow NULL? \[FALSE\]

## Value

TRUE if x is a valid string, FALSE otherwise
